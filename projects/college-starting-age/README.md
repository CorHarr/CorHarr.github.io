
# College Starting Age and Academic Performance

**Tools:** Python

## Overview

This project explores whether a student's age when entering college is associated with first-semester academic performance.

## Objective

Investigate the relationship between starting age and first-semester grades using exploratory data analysis.

## Data

Student data from the UCI Machine Learning Repository.

## Methodology

- Examined student characteristics and academic performance.
- Explored the distribution of students' starting ages.
- Investigated relationships between enrollment age and first-semester grades.
- Used exploratory analysis to identify patterns and differences.

## Analytical Focus

The analysis examines whether starting age provides meaningful information about academic performance and considers the limitations of interpreting observed relationships.

## Practical Application

Understanding how academic outcomes vary across student groups can help inform further research into student success and educational support strategies.
