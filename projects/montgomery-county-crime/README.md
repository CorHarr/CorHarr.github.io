
# Montgomery County Crime Rate Analysis

**Tools:** R

## Overview

This project compares crime rates in Montgomery County, Maryland, with other jurisdictions across the state, accounting for population differences.

## Objective

Determine how Montgomery County's crime rate compares with other Maryland jurisdictions when population size is considered.

## Data

County and state crime statistics combined with U.S. Census population data.

## Methodology

- Combined crime and population information from multiple sources.
- Calculated crime rates per capita.
- Compared crime rates across Maryland jurisdictions.
- Examined differences between total crime counts and population-adjusted rates.

## Key Findings

Montgomery County had one of Maryland's lower crime rates when population size was considered.

## Practical Application

Population-adjusted comparisons provide a more meaningful basis for evaluating public safety than raw crime totals alone.
