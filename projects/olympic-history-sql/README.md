
# 120 Years of Olympic History

**Tools:** SQL

**Status:** Planned

## Overview

This project will use SQL to explore historical Olympic participation and medal results, examining patterns across countries, athletes, and Olympic Games.

## Objective

Investigate medal performance, changes in women's participation, and potential host-country advantages through relational database queries.

## Planned Data

Historical Olympic athlete and event records covering multiple Summer and Winter Olympic Games.

## Planned Methodology

- Import and organize Olympic records into a relational database.
- Clean and validate athlete, country, event, and medal information.
- Use SQL joins, filtering, grouping, and aggregate functions.
- Analyze medal leaders by country and Olympic Games.
- Examine changes in women's participation over time.
- Investigate whether host countries demonstrate stronger medal performance.
- Present findings through summary tables and visualizations.

## Expected Application

The project will demonstrate how SQL can be used to investigate historical trends, compare groups, and answer analytical questions using structured data.

## Project Files

SQL scripts, query results, visualizations, and supporting documentation will be added as the project develops.
