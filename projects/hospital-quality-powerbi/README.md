
# Hospital Quality Ratings Dashboard

**Tools:** Power BI

**Status:** Planned

## Overview

This project will develop an interactive Power BI dashboard using publicly available Centers for Medicare & Medicaid Services (CMS) hospital quality data.

## Objective

Explore differences in hospital quality ratings across states and ownership types, providing an accessible way to examine healthcare performance patterns.

## Planned Data

CMS hospital quality data, including overall hospital star ratings, geographic information, hospital characteristics, and ownership classifications.

## Planned Methodology

- Obtain and prepare publicly available CMS hospital data.
- Clean and standardize hospital ratings and classification fields.
- Import and transform data using Power Query.
- Develop interactive Power BI visualizations.
- Compare hospital ratings across states and ownership types.
- Add filters to support exploration by geography and hospital characteristics.
- Evaluate patterns and limitations in the available data.

## Expected Application

The dashboard will support exploratory comparisons of hospital quality measures and demonstrate how interactive reporting can make complex healthcare information more accessible to decision-makers.

Hospital star ratings are summary measures and should not be interpreted as comprehensive assessments of individual hospitals.
